# Где рассказывать об обновлении

| Что получит человек                                                              | Страница релиза на GitHub                                                                                                                                   | Окно «Что нового»                                                                                                                                        |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Исправление ошибки, совместимость с устройством, дополнительные переводы         | Перечислите изменения и в одном абзаце напомните о последнем важном релизе. Подпишите этот абзац «Если вы пропустили …» и дайте ссылку на конкретную версию | Сохраните предыдущую заметку. Человек, пропустивший её, увидит её при обновлении. После закрытия приложение запомнит версию заметки                      |
| Новая возможность или заметное изменение повседневной работы                     | Опишите, кому это пригодится, где найти и как воспользоваться                                                                                               | Добавьте короткую заметку с примером действия. Она станет последней важной новостью                                                                      |
| Для сохранения данных, доступа или работоспособности нужно действие пользователя | Вынесите действие и затронутые версии в начало текста изменений                                                                                             | Добавьте заметку даже для маленького исправления. Если человек мог пропустить ещё актуальную инструкцию из прошлого релиза, повторите её в новой заметке |

Для каждой версии подготовьте `RELEASE-NOTES-v<версия>.md` на русском и английском. При публикации к нему автоматически добавляется руководство по выбору установщика. В README используйте постоянную ссылку на [последний релиз](https://github.com/egsok/klava-nevinovata/releases/latest), а ссылки на конкретные инструкции привязывайте к версии.

Файл в `src/content/release-notes/` добавляйте только тогда, когда нужно показать новое окно. Приложение выбирает одну самую свежую подходящую заметку для платформы. Оно запоминает версию закрытой заметки. При нескольких небольших обновлениях подряд ссылка «Если вы пропустили» продолжает вести на одно и то же важное обновление.

Перед выпуском проверьте два перехода через `node scripts/check-release-notes.mjs`. Человек, пропустивший важную заметку, видит её на новой версии. Человек, уже закрывший её, может сразу продолжить работу.
