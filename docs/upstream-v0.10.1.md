# Локальная тестовая версия 0.10.1-1

14.11.2026. Upstream `v0.10.1` (`aca89851`) совмещён с форком от `38718a0d`.
Ветка: `test/upstream-v0.10.1`. Точка отката: `before-upstream-v0.10.1-2026-11-14`.
Публикация и установка поверх рабочего приложения не выполнялись.

## Вставка v/м

По решению пользователя обе экспериментальные правки от 12 ноября исключены:
пакетный Windows SendInput и ожидание отпускания модификаторов. Они сохранены
отдельным коммитом `96dbf1ab` в прежней тестовой ветке.

В upstream код Windows Ctrl+V не менялся, но handy-keys 0.3.5 исправляет обработку
подавленных модификаторов. Это может относиться к наблюдаемому симптому; исчезновение
сбоя не подтверждено. Исправление похожей буквы V в Linux Shift+Insert — отдельное.

## Совмещение

- Сохранены Whisper/Breeze prompt и словарь, контекст true/128, фильтрация тишины,
  цельный повтор Whisper-диктовок, watchdog и постоянный переход на запасной хоткей.
- Сохранены атомарные настройки, Never/history 20, идентичность приложения и updater.
- Сохранена сериализация вставки/восстановления PasteLease; добавлены upstream
  предупреждение о повышенных правах окна Windows и обработка Linux PRIMARY.
- Новые уведомления объединены с ClipboardBusy. Bindings получены Rust-exporter;
  после генерации убраны только завершающие пробелы.
- handy-keys 0.3.5 включён локально в vendor: перенесены только прежние приоритет
  hook-потока и счётчик modifier_resync_count. Происхождение описано в
  `vendor/handy-keys/LOCAL-PATCHES.md`. Внешний fork не публиковался.
- Движок transcribe-cpp обновлён 0.4.0 → 0.4.2, добавлена поддержка Opus.
  Пользователь отдельно разрешил загрузку зависимостей и нативную сборку.
- Settings schema 2 → 3: на Windows меняется номер схемы, новая задержка относится
  только к Linux. Рабочие данные не мигрировались в ходе проверки.

## Проверки

- 439 Rust unit-тестов прошли; 20 были ignored в общем прогоне.
- Один из ignored — комплектная VAD-модель — отдельно прошёл синтетический тест.
  Остальные 19 интеграционных тестов supervisor с дополнительными условиями
  не выполнялись.
- 99 unit-тестов handy-keys прошли, включая новые swallowed-modifier сценарии.
- Clippy all-targets с `-D warnings`, TypeScript, ESLint, Prettier/cargo fmt,
  переводы и каталог моделей прошли.
- Debug и release Windows-сборки прошли; release включает frontend-сборку.
- Headless запуск обеих сборок в portable-режиме прошёл: загрузка CPU/Vulkan,
  перечисление 73 моделей каталога. Личных моделей и записей в тестовом профиле нет.
- GPT-6 Astra независимо проверил интеграцию и дельту vendored handy-keys;
  подтверждённых дефектов в просмотренной области не найдено.

Исходный TLS-сбой Cargo обойдён обычным HTTPS-клиентом с проверкой сертификата;
SHA256 девяти архивов совпал с Cargo.lock. Проверка TLS не отключалась.
Clippy-замечание к условной Linux-ветке устранено, Clippy и тесты повторены.
Vite сообщает о крупных чанках; это остаётся предупреждением.

## Границы

Автопроверки не подтверждают живой микрофон, реальную вставку, исчезновение v/м,
качество распознавания новым движком, установщик, macOS или Linux runtime.
Профиль, история, автозапуск и работающий экземпляр пользователя не менялись.
Новый exe агентом запускался только с отдельными пустыми portable-данными.

Полные локальные свидетельства: `target/upstream-v0101/REPORT.md`,
`CORE-MERGE.md`, `DEPENDENCIES.md`, `REVIEW.md`, `logs/`,
`validation-summary.json`, `candidate-manifest.json` (вне git).
