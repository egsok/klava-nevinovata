# klava-nevinovata 0.9.8-1 — локальная тестовая сборка

Обновление на базе Handy 0.9.8 с сохранением оформления, пользовательского промпта, словаря и доработок распознавания klava-nevinovata.

- Поиск вычислительных устройств перенесён в фон, чтобы не задерживать открытие приложения.
- Исправлена отмена после короткой записи и проверка сложных сочетаний клавиш.
- Запись не начинается, если нет доступной модели для распознавания. Пустая запись корректно завершает цикл использования модели.
- История подтверждает копирование только после успешной записи в буфер обмена.
- Для китайского языка добавлен выбор упрощённого или традиционного письма. Прежний выбор переносится автоматически.
- Обновлён движок Whisper; улучшена обработка заглавной буквы после удаления слова-паразита.

Версия предназначена для локального тестирования. Проверьте привычную диктовку, остановку и отмену записи, вставку текста и свой словарь.

# klava-nevinovata 0.9.8-1 — local test build

Based on Handy 0.9.8, preserving klava-nevinovata's design, custom prompt, vocabulary and recognition improvements.

- Compute device discovery runs in the background to avoid delaying the settings window.
- Fixed cancellation after short recordings and validation of compound shortcuts.
- Recording is blocked when no model can transcribe it. Empty recordings correctly finish the model usage cycle.
- History confirms copying only after the clipboard write succeeds.
- Added simplified/traditional Chinese script selection with migration of the previous selection.
- Updated the Whisper engine and improved sentence capitalization after removing a leading filler.

This build is for local testing. Check everyday dictation, stopping and cancelling, text insertion and your custom vocabulary.
