## Transcribing Files

klava-nevinovata is now able to transcribe files! You can do this from the history tab and click the "Transcribe File" button, or just drag and drop any file directly onto klava-nevinovata's window

## Preferred Languages and New Model Picker

You can now tell klava-nevinovata which languages you speak, and it will use that to recommend models for you. You can change them any time in **General → Preferred Languages**.

The model picker has been rebuilt around this. Every model now gets an accuracy grade (A through F) for each of your languages. klava-nevinovata picks a **Recommended** model, plus a **Faster** and a **More accurate** option, so you don't have to dig through every model to find a good one.

## Auto Language Detection

Auto now works with all transcription models. Some models can't tell which language you're speaking on their own, so klava-nevinovata uses a small language detector to figure it out. If you've selected a model which can't tell your language, you can download the detector by picking **Auto** in the language dropdown.

There is a new experimental setting to restrict auto to only your preferred languages. If you want that, go check it out!

## ONNX Models No Longer Supported

For people still using ONNX based models, support for them has been removed.
The migration screen helps download a replacement. Existing ONNX files stay on disk; you can remove them explicitly from Models. Report problems through [the fork issue tracker](https://github.com/egsok/klava-nevinovata/issues/new/choose).

## Other Changes

- **More stable:** transcription now runs in its own separate process, so if the model or your GPU crashes or hangs, klava-nevinovata itself keeps running and recovers. If the GPU was the problem, it will retry on the CPU.
- **Better errors:** they will show up in the overlay immediately as well as a tray in the app UI.
- **Language picking in the menu bar:** as it sounds, you can change your model language from the menu bar.
- **Better long audio handling:** By default, long audio, will be chunked, and this, should help long audio transcription performance as well as prevent some models from crashing. Can be turned off in **Advanced → Long Audio Chunking**.
- **New onboarding:** it should smooth things out quite a lot and make it easier for people to get started with local models.
- **Custom words work with more models:** Qwen3 ASR, Granite and others now get your custom words directly, not just Whisper.
- **AirPods Mode (macOS, experimental):** fixes recordings coming back silent when your iPhone is playing audio through your AirPods.
- Lots of smaller fixes, including better keyboard and screen reader support across settings.
