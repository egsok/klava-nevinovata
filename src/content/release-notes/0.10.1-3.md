# klava-nevinovata 0.10.1-3

- Мастер первого запуска рекомендует **Breeze-ASR-25** для русской диктовки. У Breeze в формате GGUF и её ранее загруженной версии .bin оценка **A−** для русского и английского.
- **Whisper Large v3 Turbo** получила **A−** для русского. Для сопоставимого с Breeze качества в русской речи с английскими терминами выберите русский языком распознавания и используйте **Transcription Prompt**.
- На новой установке уже выбран пресет **V3 — Ru-En**. При обновлении сохраняется ваш прежний промпт.
- При первом запуске приложение открывается в светлой теме. Обновление сохраняет выбранную тему.
- В тёмной теме мастера текст сообщений, заметок и подсказок стал контрастнее. Карточка модели поясняет, как аппаратное ускорение влияет на скорость распознавания.
