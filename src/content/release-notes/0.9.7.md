# klava-nevinovata 0.9.7-1

Обновление на базе Handy 0.9.7 с сохранением оформления, пользовательского промпта и доработок распознавания klava-nevinovata.

## Новое поведение горячей клавиши

В разделе **Общие → Поведение сочетания клавиш** теперь доступны три режима:

- **Автоматически** — удерживайте сочетание для записи и отпустите для остановки, либо нажмите кратко, чтобы начать запись, и ещё раз, чтобы остановить.
- **Удержание** — запись идёт, пока вы удерживаете сочетание. Это прежний режим «Нажми и говори».
- **Переключение** — нажмите, чтобы начать запись, и ещё раз, чтобы остановить.

При обновлении сохраняется прежний режим. Автоматический режим включён по умолчанию только для новых установок.

## Другие изменения

- Исправлена обработка конца записи, чтобы сохранять последние звуки при остановке.
- Исправлено масштабирование оверлея Windows: текст и элементы управления подстраиваются под размер окна.
- Добавлен экспериментальный детектор речи Earshot. Silero остаётся детектором по умолчанию; выбор доступен в экспериментальных настройках.
- Добавлены каталонский и индонезийский языки интерфейса. Дополнительные строки форка пока доступны на английском.

**Portable-версию обновляйте в той же папке, сохраняя `Data/` с настройками, моделями и записями.**

# klava-nevinovata 0.9.7-1 — English

Based on Handy 0.9.7, with klava-nevinovata's design, transcription prompt and recognition improvements preserved.

## New shortcut behavior

Three modes are available in **General → Shortcut Behavior**:

- **Auto** — hold to record and release to stop, or tap once to start recording and tap again to stop.
- **Hold** — record only while holding the shortcut. This is the previous push-to-talk behavior.
- **Toggle** — press once to start recording and again to stop.

Updating preserves your current mode. Auto is the default only for new installations.

## Other changes

- Fixed end-of-recording processing to retain the final audio when stopping.
- Fixed Windows overlay scaling so text and controls fit the window.
- Added the experimental Earshot voice detector. Silero remains the default; the selector is available in Experimental settings.
- Added Catalan and Indonesian interface languages. Additional fork strings currently use English.

**Update portable copies in the same folder, keeping `Data/` with settings, models and recordings.**
