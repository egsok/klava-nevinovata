# klava-nevinovata 0.10.1-2

- Расшифровка аудио и видео из файлов: добавление через «Историю» и перетаскивание, очередь заданий, поддержка Opus.
- Новый каталог моделей с рекомендациями и оценками для предпочитаемых языков; автоопределение языка с дополнительным детектором.
- Разбиение длинного аудио по паузам и изоляция движка для восстановления после ошибок.
- Старые ONNX-модели требуют замены на GGUF. Их файлы не удаляются автоматически; Whisper/Breeze `.bin` продолжают поддерживаться.
- Две доработки вставки в Windows против `v/м` вместо текста. В предварительном тесте ошибка больше не наблюдалась; окончательное устранение пока не подтверждено.
- Исправления истории, горячих клавиш, постобработки и работы на Windows, Linux и macOS.

Сохранены пользовательский промпт, словарь и другие доработки klava-nevinovata. При обновлении portable-версии сохраните папку `Data/`.

[Полное описание релиза](https://github.com/egsok/klava-nevinovata/releases/tag/v0.10.1-2)
